# Agent Security Workbench

Agent 攻击与正向业务评测、输入输出护栏、Skill 安全扫描的源码快照。

## 当前状态

这是脱敏后的初始源码版本，不是已经完成的本地演示版。

- 保留前端工作台、任务执行器、评测和 Finding 分析、保护资产管理等代码。
- 不包含真实凭据、业务数据、历史报告、私有 Prompt/Skill、生产目标目录和原仓库提交历史。
- 默认接口地址使用 `.example` 保留域名，目标编号为虚构示例，不连接原业务环境。
- 当前主要存储仍依赖 MySQL，尚未完成 SQLite 适配和演示数据初始化。
- 不附带原环境验收测试及尚未复核再分发条件的第三方策略语料。
- 策略目录仅附一个自行编写的模拟占位示例，不代表完整攻击覆盖。

仅复制源码、运行前端或配置一个模型 Key，不能完成真实 Agent 测试。

## 代码结构

| 目录 | 内容 |
| --- | --- |
| `frontend/` | Vue 工作台和服务端开发代理 |
| `auto_test/workbench/` | 任务、共享配置、报告、复核、用例库和定时计划 API |
| `auto_test/clients/` | Agent 协议适配、模型客户端和执行轨迹 |
| `auto_test/generation/`、`auto_test/runners/` | 攻击生成与执行 |
| `auto_test/business/` | 正向业务对话和评判 |
| `auto_test/judges/`、`auto_test/oracles/` | 模型评判和规则证据 |
| `auto_test/records/`、`auto_test/assets/` | 存储、报告、Finding 和资产快照 |
| `risk_guard/` | 护栏和 Skill 扫描服务 |

执行使用的评判 Prompt 与开发 Skill 属于程序资源；被测业务 Agent 的私有资产没有包含在此版本中。

## 本机检查

前端依赖和构建可单独检查：

```powershell
cd frontend
pnpm install --frozen-lockfile
pnpm build
```

完整工作台目前不能脱离数据库和自行配置的服务运行。`.env.example` 只列出配置项，不提供真实访问权限；真实配置文件不会纳入 Git。

## 后续适配

1. 为任务、用例、报告和运行资料增加 SQLite 存储与初始化。
2. 编写明确标为模拟的示例数据、保护资产和策略，不导出原业务数据库。
3. 增加本地模拟 Agent，让基本演示不依赖外部服务。
4. 保留可选真实测试入口，由使用者自行配置授权接口及模型 Key。
5. 补充公开版本专用测试、启动入口和操作说明。

## 使用边界

仅对明确授权的目标执行测试。模拟结果不能作为真实产品评测证据。配置文件、SQLite 运行库、上传的扫描包和生成报告均不应直接加入版本管理。

本初版尚未选择开源许可证；私有保存源码不等于已经授予公开再分发许可，公开发布前还需复核许可及第三方资源来源。
